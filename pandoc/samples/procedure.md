# 目的

この文書は、Markdownで書いた手順書をPandocでHTML化するためのサンプルです。作業前確認、実施手順、確認観点、切り戻しの見え方を確認します。

# 作業前確認

::: {.checklist}
**開始条件**

- 対象ブランチのCIが成功している
- リリース対象のバージョン番号が確定している
- 作業者と確認者が同じ手順書を参照している
:::

# 実施手順

## ビルド

1. 対象リポジトリを最新化します。
2. 依存関係をインストールします。
3. ビルドを実行します。

```powershell
npm ci
npm run build
```

## デプロイ

1. リリースタグを作成します。
2. デプロイジョブを実行します。
3. ジョブ完了後、成果物のバージョンを確認します。

::: {.warning}
**注意:** 本番反映中は、同じ環境に対する別作業を開始しないでください。
:::

# 確認

| 観点 | 確認内容 | 結果 |
| --- | --- | --- |
| 画面 | トップページが表示できる |  |
| API | ヘルスチェックが成功する |  |
| ログ | エラーが継続発生していない |  |

# 切り戻し

切り戻しが必要な場合は、直前の安定バージョンを指定してデプロイします。

```powershell
.\deploy.ps1 -Version 1.2.2
```
