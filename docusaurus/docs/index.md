このサイトは、設計書、手順書、判断記録、運用ランブックを継続的に管理するための雛形で、個人用ドキュメントツールキット（docs-toolkit）の利用ガイドも兼ねています。装飾を抑えた簡潔なレイアウトで、読み手が必要な情報へ素早く到達できることを優先します。

## 文書タイプ

| 文書 | 読み手の目的 | 使用する場面 |
| --- | --- | --- |
| [設計書](./document-templates/design-document.md) | 実装・レビューに必要な方式と影響を理解する | 機能追加、構成変更、連携設計 |
| [手順書](./document-templates/procedure.md) | 作業を安全に実施し、完了を確認する | リリース、移行、定型作業 |
| [判断記録](./document-templates/decision-record.md) | 選択理由と見直し条件を追跡する | 方式選定、例外承認、方針変更 |
| [運用ランブック](./document-templates/runbook.md) | 事象を切り分け、復旧判断を行う | 障害対応、アラート対応、一次調査 |

## ツールキットの利用ガイド

Marp / Slidev / Pandoc / 図解基盤 / Docusaurus の「最初の一歩」は[ツールキット概要](./guide/index.md)から辿れます。

## 最初に読むもの

1. [文書運用](./conventions/document-policy.md)で、文書タイプと管理単位を決めます。
2. [書き方](./conventions/writing-style.md)で、見出し、表、注記、コードのルールを確認します。
3. 用途に合うテンプレートをコピーし、不要な章を削除して使います。

:::note[運用の原則]
文書の完全性より、読み手が判断または作業できることを優先します。事実、判断、未決事項、確認方法を分けて記述してください。
:::
