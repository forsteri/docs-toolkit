## 実施手順

### 1. 準備

1. 対象リポジトリを最新化します。
2. 依存関係をインストールします。
3. 設定値を確認します。

```bash
npm ci
npm run build
```

期待結果: ビルドが終了コード`0`で完了し、エラーが出力されないこと。

### 2. 反映

1. リリースタグを作成します。
2. デプロイジョブを実行します。
3. ジョブ完了後、成果物のバージョンを確認します。

:::warning[注意]
本番反映中は、同じ環境に対する別作業を開始しないでください。
:::

### 3. 確認

| 観点 | 確認内容 | 期待結果 | 結果 |

| API | ヘルスチェックを実行する | `healthy` |  |
| ログ | エラーログを確認する | 継続エラーなし |  |
