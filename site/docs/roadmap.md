# ロードマップ

方向性の正本は docs-toolkit の [ROADMAP.md](https://github.com/forsteri/docs-toolkit/blob/main/ROADMAP.md) です。このページはその要約です。

> 必要な文書を、開発プロジェクトの正しい場所に作り、検査し、人が判断できる形で共有する。

## ここまで

1. 6リポジトリへ分割した
2. 色とフォントを役割名のトークンへ移した（全サンプルの描画が差分ゼロ）
3. 架空の案件（Hakobi Track）で試し、見つかった改善15件を反映した
4. docs-toolkit を入口リポジトリにし、`brand/` と横断の検査を置いた
5. ブランド面の穴（系列色1・Night）を埋めた
6. **説明に使い始めた**：変更の説明の型と、このサイト
